# MasterIris

MasterIris is a high-performance, event-driven data processing platform leveraging microservices architecture and auto-scaling capabilities.

MasterIris is built to be simple and practical, focusing on doing one thing well.

**Why MasterIris?**

- MasterIris is a high-performance, event-driven
- data processing platform leveraging microservices
- architecture and auto-scaling capabilities

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/MasterIris.git`
2. `cd MasterIris`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
